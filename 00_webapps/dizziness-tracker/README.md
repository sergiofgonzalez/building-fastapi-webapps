# Dizziness Tracker
> a simple FastAPI web app to track diziness episodes


## Setting up shop

The application has been built incrementally, with a folder for each iteration. You will find in the corresponding `README.md` file specific stuff about that iteration.

All the projects are managed with `uv`.

The projects are created doing:

```bash
$ uv init 01_dizziness-tracker_hello-fastapi
```

Then you can run the project doing:

```bash
$ uv run
```
